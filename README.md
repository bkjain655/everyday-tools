# Everyday Tools - Multi-purpose Developer & User Tools

This is a comprehensive collection of utilities for developers and everyday users, built with Next.js 14, Tailwind CSS, and radix/ui components.

## 🚀 Features

Everyday Tools includes a wide range of tools organized into categories:

### Developer Tools
- UUID Generator - Create random UUIDs with different versions
- QR Code Generator - Create customizable QR codes
- JWT Decoder - Decode and verify JWT tokens
- JSON Formatter - Format, validate, and minify JSON
- Hash Generator - Generate MD5, SHA-1, SHA-256, SHA-512 hashes
- Base Converter - Convert between different number bases

### Image & Text Tools
- OCR Tool - Extract text from images
- Image to Base64 - Convert images to base64 encoding
- Character Counter - Count characters, words, and more in text

### Calculation Tools
- Interest Calculator - Calculate simple and compound interest
- Loan EMI Calculator - Calculate loan EMIs with amortization schedules
- Metric Converter - Convert between different units of measurement

### Date & Time Tools
- Time Zone Converter - Convert times between different time zones
- Date Calculator - Calculate differences between dates and add/subtract time

### Design Tools
- Color Converter - Convert between HEX, RGB, HSL color formats

## 🛠️ Technologies Used

- [Next.js 14](https://nextjs.org/) - React framework
- [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework
- [radix-ui](https://www.radix-ui.com/) - UI component library
- [Tesseract.js](https://tesseract.projectnaptha.com/) - OCR engine
- QR code generation

```bash

# Navigate to the project directory
cd everyday-tools

yarn
